# Security Policy

## Scope

ProofMesh Guard is an open-source hackathon build and devnet-oriented SDK. It
is not a custody system, an escrow system, or a security guarantee for a
production treasury. Do not use the repository's fixtures, demo wallets, or
captured evidence as production credentials.

## Reporting A Vulnerability

If the repository's GitHub Security tab offers `Report a vulnerability`, use
that private channel. Availability depends on the repository settings and is
not assumed by this policy. Do not open a public issue for an undisclosed
vulnerability, and do not include private keys, credentials, or sensitive
customer data in a report.

If private reporting is unavailable, contact the maintainer through the public
GitHub profile at <https://github.com/Vetassikc> and request a private channel.
Include:

- the affected file, package, or program instruction;
- the smallest reproducible example;
- the security impact and any required assumptions; and
- a suggested mitigation, if known.

## Response Expectations

This is a founder-maintained project. Reports will be acknowledged when the
maintainer can review them. Fix timing depends on severity, reproducibility,
and whether the affected path is demo-only, devnet-only, or reusable SDK code.

Please allow reasonable time for investigation before public disclosure.
